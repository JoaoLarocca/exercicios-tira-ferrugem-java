# Tira Ferrugem do Cérebro 🧠☕

Repositório dedicado ao armazenamento dos exercícios desenvolvidos durante as atividades de **retomada de conteúdo** da disciplina de programação.

O objetivo é revisar e praticar os conceitos fundamentais da linguagem **Java**, reforçando a lógica de programação por meio de desafios progressivos que envolvem **vetores, matrizes, estruturas de repetição, condicionais, ordenação e manipulação de dados**.

---

## 📋 Exercícios

| Arquivo | Tema | O que é praticado |
|---------|------|-------------------|
| [`EX1.java`](./EX1.java) | **Notas dos alunos** | Leitura e armazenamento de notas em vetor; cálculo de média, maior e menor valor; uso de estruturas de repetição e condicionais. |
| [`EX2.java`](./EX2.java) | **Diagonais de uma matriz** | Construção de matriz quadrada; percorrimento e extração da diagonal principal e da diagonal secundária. |
| [`EX3.java`](./EX3.java) | **Valores distintos** | Verificação de elementos repetidos em um conjunto; contagem e listagem de valores únicos. |
| [`EX4.java`](./EX4.java) | **Rotação de matriz** | Manipulação de índices para rotacionar os elementos de uma matriz (sentido horário/anti-horário). |
| [`EX5.java`](./EX5.java) | **Bubble Sort e mediana** | Implementação manual do algoritmo **Bubble Sort**; ordenação de vetor e cálculo da mediana dos valores. |
| [`EX6.java`](./EX6.java) | **Quadrado mágico** | Verificação se uma matriz quadrada é um quadrado mágico (somas iguais em linhas, colunas e diagonais). |
| [`EX7.java`](./EX7.java) | **Batalha Naval** | Simulação de tabuleiro; posicionamento de navios, leitura de jogadas e verificação de acertos. |
| [`EX8.java`](./EX8.java) | **Sistema de assentos de cinema** | Gerenciamento de reservas em uma sala; controle de assentos ocupados/livres e interação com o usuário. |

---

## 🛠️ Tecnologias e Conceitos

- **Linguagem:** Java
- **IDE:** NetBeans
- **Conceitos praticados:**
  - Vetores e matrizes
  - Estruturas de repetição (`for`, `while`, `do-while`)
  - Estruturas condicionais (`if`, `else`, `switch`)
  - Algoritmos de ordenação (Bubble Sort)
  - Manipulação e validação de dados

## ▶️ Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/Lista_Ferrugem.git
   ```
2. Abra cada arquivo `.java` no **NetBeans**, **IntelliJ** ou **VS Code**.
3. Compile e execute individualmente:
   ```bash
   javac EX1.java
   java EX1
   ```

> 💡 Como cada arquivo tem sua própria classe `main`, todos podem ser executados de forma independente.
